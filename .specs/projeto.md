# Buskai — Contexto do Projeto

## O que é
Diretório curado de ferramentas de IA para o mercado LATAM (PT-BR).
Site: https://www.buskai.net
Repositório: fcferraz/getbench-site

## Stack
- Framework: Astro SSR
- Deploy: Vercel (automático via push para main)
- Banco de dados: Airtable (base appFwfYV1xtqMcEMg)
- Versionamento: GitHub

## Fase atual
Phase 1 — Consolidação PT-BR
- 160+ ferramentas publicadas no diretório
- 14+ artigos no blog
- AdSense: segunda submissão pendente de aprovação
- Phase 2 (/en/ + hreflang) bloqueada até aprovação do AdSense

## Estrutura do site
- `/` — home com diretório de ferramentas
- `/blog` — artigos editoriais
- `/categories/[slug]` — páginas de categoria
- `/tools/[slug]` — página individual de ferramenta
- `/alternativas/[slug]` — páginas de pSEO
